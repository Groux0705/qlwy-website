## 2. 核心NFT系统

### 2.1 FortuneCore协议

FortuneCore是潜龙勿用的核心NFT协议，负责生成和管理具有运势属性的NFT。每个NFT代表一条「龙」，拥有独特的六爻卦象和幸运值。

### 2.2 六爻卦象

基于《易经》64卦体系，每个NFT都包含：
- **主卦**: 64卦中的某一卦
- **六爻**: 每一爻的阴阳状态
- **卦辞**: 解释整个卦象的含义

### 2.3 五级稀有度

| 稀有度 | 中文名 | 概率 | 幸运加成 | 特征 |
|--------|--------|------|----------|------|
| Common | 普通卦 | ~85.9% | +0 | 基础NFT |
| Rare | 稀有卦 | 10% | +5 | 可升级为签灵 |
| Epic | 史诗卦 | 3% | +10 | 高级战斗单位 |
| Legendary | 传奇卦 | 1% | +15 | 稀缺战斗精英 |
| Mythic | 神话卦 | 0.1% | +20 | 最高等级，参与奖池分红 |

### 2.4 NFT属性

**幸运值 (Luck Value)**
- 范围: 0-100
- 影响战斗评分和预测准确率
- 可通过升级提升

**等级 (Level)**
- 范围: 0-99
- 通过战斗获得经验值升级
- 更高等级带来更好属性

### 2.5 进化路径

```
普通卦 → 稀有卦 → 史诗卦 → 传奇卦 → 神话卦
```

## 3. 游戏机制

### 3.1 卜卦系统 (Divination)

卜卦是获取NFT的主要方式，通过区块链随机数生成独特的卦象。

#### 操作流程

1. **请求卜卦**: 支付0.005 BNB
2. **等待VRF**: 约10秒链上随机数生成
3. **铸造NFT**: 稀有及以上直接mint到钱包

#### 铸造费用

| 稀有度 | 铸造费用 (QLWY) |
|--------|-----------------|
| 稀有 (Rare) | 50 |
| 史诗 (Epic) | 100 |
| 传奇 (Legendary) | 500 |
| 神话 (Mythic) | 2000 |

#### 费用分配

- **70%**: 通过PancakeSwap注入奖池
- **30%**: 进入质押池

### 3.2 PVP战斗

3v3团队对战系统，使用签灵NFT进行战斗。

#### 战斗评分公式

```
战斗得分 = 有效幸运值 × 70 + 随机数 × 30
```

其中有效幸运值 = 基础幸运值 + 稀有度加成

|--------|--------|

### 3.3 奖池系统 (Jackpot)

奖池是潜龙勿用独特的通缩和激励机制。

#### 触发条件

每次铸造神话(Mythic)NFT时触发奖池分配。

#### 分配规则

| 分配对象 | 比例 |
|----------|------|
| 新Mythic持有者 | 50% |
| 现有Mythic持有者 | 30% |
| 合约保留(下一轮) | 20% |

#### 神话NFT上限

- 最大数量: 88个
- 达到上限后，奖池全额分配给所有Mythic持有者
- 奖池重置，新一轮开始

1. **项目初始化**: 开发者注入10M QLWY (代币总量的1%)
2. **卜卦费用**: 70%通过BNB→QLWY兑换注入
3. **铸造费用**: 神话铸造费用全额注入
4. **用户捐赠**: 任何人都可以向奖池贡献

### 3.4 签灵Agent (Spirit Agent)

签灵是基于BAP-578标准的AI Agent，将普通NFT升级为智能化自治实体。

#### 核心特性

- **包裹升级**: 通过_wrap函数将NFT升级为AI Agent
- **等级系统**: 0-99级，通过经验值升级
- **自动化**: 支持自动战斗、自动预测、自动卜卦
- **不可转移**: msg.sender始终代表签灵本身，确保安全
- **学习能力**: 能够学习用户偏好并持续优化

#### 升级要求

- 仅限稀有(Rare)及以上NFT
- 参与当前战斗需最低500代币
- 需要BNB作为自动化操作的gas费用

## 5. 预测市场

### 5.1 LMSR AMM机制

潜龙勿用预测市场采用**对数市场评分规则**(Logarithmic Market Scoring Rule, LMSR)作为自动做市商机制。

#### 成本函数

```
Cost = b × ln(e^(q_yes/b) + e^(q_no/b))
```

#### 价格公式

```
P_yes = e^(q_yes/b) / (e^(q_yes/b) + e^(q_no/b))
```

#### 流动性参数b

- **较高b**: 价格滑点小，但做市商最大损失较高
- **较低b**: 交易对价格影响大

### 5.2 市场类型

- **YES/NO预测**: 简单的二元预测
- **结算货币**: USD1稳定币

### 5.3 费用结构

| 角色 | 比例 |
|------|------|
| 创建者 | 1% |
| 协议 | 1% |
| LP | 1% |

### 5.4 市场生命周期

```
PENDING → TRADING → DISPUTE PERIOD → ARBITRATION → RESOLVED
```

1. **PENDING**: 创建和审核阶段
2. **TRADING**: 活跃交易阶段
3. **DISPUTE PERIOD**: 到期后24小时争议窗口
4. **ARBITRATION**: (仅在有争议时) 神话NFT持有者投票
5. **RESOLVED**: 最终结算
